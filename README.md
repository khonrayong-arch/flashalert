# FlashAlert - เริ่มใหม่แบบสะอาด

## วิธีติดตั้ง (ทำตามนี้เป๊ะๆ)

1. สร้าง repo ใหม่บน GitHub ชื่อ `flashalert` (ไม่มีขีด - นำหน้า)
   https://github.com/new
   - ชื่อ: flashalert
   - Public
   - ไม่ต้องติ๊ก Add README

2. แตกไฟล์ zip นี้ แล้วอัพโหลดทั้งหมดขึ้นไป
   - เข้าไปในโฟลเดอร์ FlashAlert-CLEAN ที่แตกมา
   - เลือกไฟล์ทั้งหมด (Ctrl+A)
   - ลากไปวางในหน้า GitHub ที่บอกว่า "upload files"

3. รอ GitHub Actions build อัตโนมัติ 3 นาที
   - ไปแท็บ Actions จะเห็นสีเหลืองกำลังรัน
   - พอเขียวแล้วกดเข้าไป > ดาวน์โหลด app-debug.apk

จบ!
